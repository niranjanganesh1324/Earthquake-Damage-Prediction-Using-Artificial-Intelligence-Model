Abstract


Earthquakes are a natural disaster that causes damage to personnel and property.
While personnel protection and safety is a well planned response, so can
property safety be. This paper presents a LightGBM based machine learning
classification model that predicts building damage grades using key features
such as floor count, age, plinth area, roof type, and earthquake intensity
measures for the Country of Nepal.


Based on the predicted Earthquake Damage grade for a building, measures can
be taken to either structurally improve it or the model can be used to predict the
damage that would be taken by a building project that is yet to be developed,
thereby giving an approximate view in to the future, so that the design can be
perfected for Earthquake dense areas.


This model is based on the Nepal 2015 Earthquake Data of the buildings and
areas, but can be extended to any Earthquake prone country if the relevant data
is collected and given to the model for training.
The model achieves 90.37% overall accuracy and a weighted F1 score of 0.904,
performing well across all damage grades. A user friendly GUI allows real time
predictions, offering actionable insights for engineers, planners, and emergency
responders, enabling faster and more informed post earthquake decision
making.

Introduction


Earthquakes cause severe damage to buildings, posing risks to life and
infrastructure. Rapid damage assessment is critical for effective disaster
response but manual inspections are slow and error prone.


Machine learning offers a faster, automated approach by predicting building
damage from structural and site-specific features. This study presents a
LightGBM based model trained on Nepal earthquake data, using 13 key features
and derived metrics.




The model achieves high accuracy and F1 scores across damage grades.

Related Work


Earthquake damage prediction has traditionally relied on post event surveys,
which are slow and error prone. Recent studies use machine learning models
like Random Forests, XGBoost, and LightGBM with structural, geographical,
and seismic features, achieving faster and more accurate assessments.


This work extends prior research by incorporating derived metrics such as
intensity ratios and floor heights and providing a real time prediction interface
for practical disaster management.




Methodology


The proposed system predicts building damage grades (0-4) using a LightGBM
model trained on Nepal earthquake ward-level data.

Results and Discussion


The LightGBM model achieved an overall accuracy of 90.37% on the test set.
Detailed evaluation using precision, recall, and F1 score demonstrates strong
performance across all damage grades:

Incorporating derived features such as intensity ratios, floor height estimations,
and ward level damage means improved predictive performance, especially for
moderate and extensive damage grades.

Conclusion


This study presents a machine learning-based system for rapid earthquake
damage assessment of buildings. Using a LightGBM model trained on Nepal
ward-level data, the system predicts damage grades (0-4) with high accuracy
(90.37%) and a weighted F1 score of 0.9044.
By incorporating both buildings specific features and derived metrics such as
intensity ratios and floor height estimations, the model effectively captures
structural vulnerability.
The user friendly GUI enables real time predictions, bridging the gap between
models and practical disaster management applications.
This approach can significantly aid engineers, urban planners, and emergency
responders in prioritizing interventions, ultimately contributing to safer, more
resilient communities.
